# FlowCraft Showcase Scope

This public repository is intentionally limited.

## Included

- Product overview.
- Public feature summary.
- Screenshots hosted on GitHub.
- Creator and ownership information.
- Safe .NET metadata project for language classification.

## Excluded

- Production source code.
- Runtime parser and serializer logic.
- Proprietary `.dig` / `.dml` implementation details.
- Internal runtime assets.
- Commercial build, publish, installer, and obfuscation configuration.
- Private test data.
- Customer-specific integrations.
- Internal AI prompt implementation details beyond public capability descriptions.

## Product Areas Described Publicly

- Visual graph editing.
- Package navigation.
- Search, replace, validation, command palette, variables, and diff/compare tooling.
- AI-assisted flow patch generation.
- Flow-linked UI screen designer.
- React-style UI export capability.
